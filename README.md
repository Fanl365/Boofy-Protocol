# Boofy Protocol

Boofy Protocol is the protocol-level repository for the Boofy DeFi project. It contains protocol architecture, governance/deployment-related source material, and supporting components that sit alongside Boofy App, Boofy API, and Boofy Contracts.

> **Development status:** active migration and protocol definition. Historical upstream deployment identifiers are preserved for traceability but are not automatically valid Boofy production values.

## Project goals

- Define a clear protocol architecture for Boofy.
- Separate historical upstream deployment data from future Boofy deployments.
- Document governance, ownership, and operational assumptions.
- Coordinate protocol changes across App, API, and Contracts.

## Current work

The active protocol tracks are:

1. Protocol naming and documentation cleanup.
2. Deployment-boundary and ownership documentation.
3. Coordination with Boofy Contracts and API configuration.
4. Governance and release-readiness planning.

See [ROADMAP.md](ROADMAP.md) and repository Issues for current work.

## Repository history

Boofy Protocol preserves the upstream development history used as its technical foundation. Historical commits retain their original authorship and timestamps. Current Boofy development is tracked through new commits and issues.
